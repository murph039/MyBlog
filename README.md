# My blog

This folder is both an Obsidian vault and a GitHub Pages site.

- Write posts in `_posts`, named like `2026-10-13-my-post-title.md`
- Keep unfinished writing in `_drafts` (never published)
- Images go in `assets` (no spaces in filenames)
- To publish: open the matching folder on GitHub, Add file → Upload files, drag the file in, commit
